## ADC란 무엇이고 왜 필요한가?

마이크로 컨트롤러 내부는 0과 1로 동작합니다. 각종 센서 등 현실 세계의 신호는 대부분 아날로그의 전압입니다.
ADC는 이러한 아날로그 전압들을 일정한 간격으로 ‘스냅샷’ 찍어서 디지털 코드로 바꿔주는 회로입니다.

Atmega128의 ADC)
- 10비트 -> 1023 사이의 정수로 표현합니다.

축차근사: 내부에 있는 DAC와 비교기를 이용해 이진 탐색처럼 한 비트 씩 확정해 나아가는 방식

## 2. Atmega128 스펙

- 분해능: 10비트 -> 1024단계로 쪼갬
- INL: 0.5LSVB(선형성이 매우 좋음
- 절대 정확도: +- 2LSB(실제 오차범위 약 +- 0.2%)
- 변환 시간: 13~260ms
- 최대 샘플링 속도: 76.9kSPS
- 단일 입력 채널: 8개(ADC0~7, PORTF)
- 차동 입력 조합: 16가지
- 게인 지원 차동 쌍: ADC 0,1 / ADC 2,3
- 게인 배율: 1X/10X(20dB) -> 배율이 클수록 유효 분해능 감소
- 결과 정렬: 좌측, 우측 정령 선택
- 입력 범위: 0~5V
- 기준 전압: AREF/AVCC/내부 2.56V
- 동작 모드: Single Conversion / Free Running
- 인터럽트: 변환 완료 시 발생 (ADIF)

## 3. 내부 구조 회로

ADC는 크게 6개의 블록으로 나눌 수 있습니다.

**1) 입력 멀티 플렉서**
ADC 핀 중 하나를 +로, 하나는 –로 선택하는 아날로그 스위치 모음

**2) 게인 증폭기**
POS와 NEG 입력의 전압 차이 증폭
단일 입력 모드에서는 이 블록 완전히 스킵
차동모드에서만 활성화

**3) 싱글엔디드 / 차동 선택**
게인 증폭기를 거친 신호 vs 원본 신호 중 어느 것을 실제 입력으로 넣을지 선택

**4) 샘플, 홀드 비교기**
변환이 진행되는 동안 입력 전압이 흔들리지 않도록 커패시터에 전하 저장

**5) 변환 로직**
SAR 알고리즘을 실행하는 디지털 제어 회로
프리 스케일러가 CPU 클럭을 ADC에 적합한 저속 클럭으로 낮춰서 공급

**6) ADC 데이터 레지스터(ADCH/ADCL)**
변환이 끝난 10비트 결과가 저장되는 곳

## 4. 축차근사 변환이 일어나는 방식

**1) 핵심 아이디어 풀이**
내부 DAC를 입력 범위의 절반 값으로 설정
비교기 >입력 전압인지 판단 -> 크면 최상위 비트는 1, DAC 절반 구간의 중간값으로 설정
이 과정을 10번 반복하여 10비트가 모두 확정됨

**2) 정리**
10비트 해상도를 위해서는 최소 10번의 사이클 필요 + 샘플링 필요 시간까지 더해져서 13ADC 클럭 사이클이 소요됨.

## 5. ADC 전체 사용 흐름

1) ADMUX 설정 : 어떤 채널을, 어떤 기준전압으로, 어떤 정렬로 읽을지 결정
2) ADCSRA.ADEN=1 : ADC 전원 및 회로 활성화
3) 더미 변환 1회 실행 후 결과 버리기 : 초기화 지연/정착시간 소진
4) ADCSRA.ADSC=1 : 실제 변환 시작
5) 대기 : ADIF 폴링 또는 인터럽트(ADIE=1) 방식으로 완료 감지
6) 결과 읽기 : (우측정렬) ADCL 먼저 → ADCH 나중에
7) ADIF 클리어 : 폴링 방식이면 플래그에 1을 써서 클리어 (또는 인터럽트 진입 시 자동 클리어)


## 6. 프리스케일러와 타이밍 완전 분석

**1) 프리스케일러 구조**
- 7비트 카운터로 CPU 클럭(CK)을 나눠서 ADC 클럭을 만듦
- 나눌 수 있는 값: 2, 4, 8, 16, 32, 64, 128
- 동작 규칙: ADEN=1이 되는 순간부터 카운트 시작. ADEN=0이면 계속 리셋

**2) 왜 50~200kHz 범위를 권장하는가?**
ADC 내부의 비교기와 DAC가 이 주파수 대역에서 최적의 정밀도(10비트급)를 내도록 설계되었습니다.
클럭이 너무 빠르면(200kHz 초과) 비교기가 안정화되기 전에 다음 비트를 판단하게 되어 정확도가 떨어짐
클럭이 너무 느리면 변환 시간이 길어져 샘플링 속도가 떨어짐.

## 7. 차동 게인 채널 분석

**1) 왜 차동 입력이 필요한가?**
단일 입력은 항상 GND를 기준으로 측정하므로, 두 지점 사이의 미세한 전압차를 측정하려면
큰 공통전압에 묻혀서 정밀도가 떨어짐 차동 입력은 두 지점의 "차이"만 뽑아내고
게인으로 증폭하기 때문에 미세 신호 측정에 유리함

**2) 동기화 메커니즘**
차동 변환은 ADC 클럭의 절반 속도인 내부 클럭에 동기화되어 시작됨
이는 아날로그 회로의 안정성을 보장하기 위한 설계

**3) 게인 스테이지의 대역폭 제한**
게인 증폭기는 모든 배율에서 4kHZ 대역폭으로 최적화됨
이보다 높은 주파수 성분이 입력에 섞여있다면 왜곡이 생길 수 있음
해결: 외부 저역통과 필터로 4kHZ 이상 성분을 미리 제거

**4) 정착 시간**
차동 채널을 새로 선택하면, 게인 스테이지가 새로운 신호에 안정되기까지 125ms 걸릴 수 있음

## 8. 채널/기준 전압 변경의 함정들

ADMUX의 MUX/REFS 비트는 더블 버퍼링 구조라서, 아무 때나 값을 바꿔도
즉시 반영되지 않고 안전한 타이밍에만 실제로 적용됩니다.

**1) 반영 타이밍 규칙**
- 변환이 시작되지 않은 동안: 값을 쓰면 계속 최신 값으로 업데이트됨
- 변환이 시작되면: 그 순간 값이 잠김 — 변환 도중 값을 바꿔도 그 변환에는 영향 없음
- 변환 완료 직전 마지막 사이클(ADIF 세팅 시점)에 다시 업데이트가 재개됨

**2) 왜 ADSC 쓴 직후 1사이클을 조심해야 하나?**
변환은 ADSC를 쓴 다음 ADC 클럭의 다음 상승 엣지에서 실제로 시작됨
그 사이(ADSC를 쓴 순간 ~ 다음 상승 엣지 전)에 ADMUX를 다시 쓰면 타이밍이 꼬일 수 있음
권장: 아예 ADSC를 쓰기 전에 채널을 확정하고, 변환 중에는 건드리지 않는 것이 가장 안전함

## 9. 전압 기준 선택 전략

AREF 외부핀 직접 입력인 경우: 특수한 정밀 기준 전압 IC를 쓰고싶을 때 사용
AVCC: 배터리 등 전원이 다소 qusehdog도 큰 상관없는 범용 측정일 때 사용
내부 2.56V: 전원 전압과 무관하게 안정적인 절대 기준이 필요할 때 사용

## 11. 아날로그 입력 회로

**1) 등가 회로 모델**
누설 전류: 그 채널이 선택되지 않아도 항상 존재하는 미세 전류를 조심히 봐야함.
직렬저항: 채널이 선택되었을 때만 경로에 들어가는 저항. 충전 시간을 결정함

**2) 소스 임피던스가 왜 중요한가**
RC회로 특성: 임피던스가 높을수록 커패시터를 충전하는 데 오랜 시간이 걸림
샘플링 시간이 짧아서 소스 임피던스가 크면 커패시터가 완전히 충전되지 못함
해결: 임피던스가 높은 소스를 쓴다면 버퍼 앰프를 앞단에 추가해 임피던스를 낮춰줘야함

## 12. PCB 설계 관점의 노이즈 저감

**1) 아날로그 경로 최소화:** 아날로그 신호선은 최대한 짧게, 그라운드 플레인 위로 배선. 디지털 고속 신호선(과는 물리적으로 멀리 떨어뜨림.

**2) AVCC LC 필터링:** AVCC를 디지털 VCC와 직접 연결하지 않고 인덕터 + 커패시터 로 구성된 저역통과 필터를 거쳐 연결

**3) 노이즈 캔슬러 적극 활용:** 특히 정밀 측정에는 11장의 노이즈 캔슬러를 사용.

**4) 동적 핀 사용 자제:** ADC로 쓰는 포트 핀들 중 일부를 디지털 출력으로 겸용한다면, 변환이 진행되는 동안에는 그 핀들이 절대 스위칭(토글)하지 않도록 소프트웨어에서 통제해야 합니다. 스위칭 노이즈가 바로 옆 채널의 변환 정확도를 해침

## 13. 전원 배선도 및 오프셋 보정 실전

**1) 전원 연결**
- AVCC(64번 핀): 10μH 인덕터를 통해 VCC(52번 핀)와 연결, 100nF 커패시터로 GND에 디커플링.
- AREF(62번 핀): 외부 기준전압 또는 디커플링 커패시터 연결용.
- ADC0-ADC7(핀 61~54, PF0~PF7): 아날로그 입력.

**2) 오프셋 보정**
게인 스테이지는 내장 오프셋 상쇄 회로를 지님 -> 차동 측정 오프셋을 자동으로 제거
남은 오프셋 잔차는 양쪽 차동 입력에 같은 채널을 선택하여 직접 측정 가능
측정된 오프셋 값을 소프트웨어에서 결과값에서 뺴주면 어떤 채널이든 오프겟은 1LSB이하로 감소 가능

## 14. ADC 정확도 6대 지표 완전 정리

- 오프셋: 첫 번째 전이가 이상적 위치(0.5LSB)에서 벗어난 정도
- 게인 오차: 오프셋 보정 후 마지막 전이가 이상 위치(0.5LSB)에서 벗어난 정도
- 적분 비선형성: 오프셋, 게인 보정 후, 임의 코드에서 실제 전이와 이상 전이의 최대 편차
- 미분 비선형성: 실제 코드 폭(인접 두 전이 사이 간격)과 이상 코드 폭(1LSB)의 최대 편차
- 양자화 오차: 입력을 유한한 코드로 양자화하며 발생하는 근본적 오차
- 절대 정확도: 오프셋 + 게인 오차+ 비선형성 + 양자화 오차를 모두 합친 실제 전이의 최대 편차

## 15. 변환 결과 계산 공식

**1) 단일 입력 변환**
- ADC = (VIN x 1024) /VREF (VIN: 선택된 입력 핀의 전압 / 0X000 : GND)

**2) 차동 변환**
ADC = (VPOS − VNEG) × GAIN × 512 / VREF
결과는 2의 보수 형태

## 16. 레지스터란?

**1) ADMUX(ADC Multiplexer Selection Register)**
REFS1:0 — 기준전압 선택

변환 도중 값을 바꿔도 현재 변환이 끝날 때까지 적용 안됨

| REFS1 | REFS0 | 선택 |
| --- | --- | --- |
| 0 | 0 | AREF, 내부 기준 off |
| 0 | 1 | AVCC |
| 1 | 0 | 예약 |
| 1 | 1 | 내부 2.56V |

**2) ADLAR**
결과 좌측 정렬, 우측 정렬
진행 중인 변환과 무관하게 즉시 반영

**3) MUX4:0**
- 00000-00111: 단일 입력 ADC0~ADC7
- 01000-01111: 차동 쌍 (ADC0/ADC1, ADC2/ADC3) × 게인(10x/200x)
- 10000-11101: 차동 쌍, 공통 음극 ADC1 또는 ADC2, 게인 1x
- 11110: 1.23V 밴드갭 기준전압 (오프셋 보정용)
- 11111: 0V (GND)
- 변경사항도 REFS와 마찬가지로 진행 중 변환 완료 후 반영됨.

**4) ADCSRA(ADC Control and Status Register A)**
- ADEN: ADC 활성화(1)/비활성화(0). 변환 중 끄면 즉시 중단.
- ADSC: 변환 시작 트리거. 변환 중엔 1 유지, 완료 시 자동 0.
- ADFR: 프리 러닝 모드 선택(1). 0으로 쓰면 프리 러닝 종료.
- ADIF: 변환 완료 인터럽트 플래그. ISR 실행 시 하드웨어가 자동 클리어, 또는 1을 써서 수동 클리어 가능.
- ADCSRA를 read-modify-write(예: SBI/CBI 명령)하면 대기 중인 인터럽트가 disable될 수 있으므로 주의.
- ADIE: 인터럽트 활성화
- ADPS2:0: 프리스케일러 분주비 선택

**5) ADC 프리스케일러 선택표**

| ADPS2 | ADPS1 | ADPS0 | 분주비 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 2 |
| 0 | 0 | 1 | 2 |
| 0 | 1 | 0 | 4 |
| 0 | 1 | 1 | 8 |
| 1 | 0 | 0 | 16 |
| 1 | 0 | 1 | 32 |
| 1 | 1 | 0 | 64 |
| 1 | 1 | 1 | 128 |
