# UART 통신에 사용되는 232 통신과 485 통신에 대한 보고서

*수습단원 최윤서*

## 232 통신

컴퓨터와 주변 장치르 연결하는 비동기식 직렬 통신 규격으로 TXD, RXD, GND 3개의 핵심 선을 주로 사용함.
총 9개의 핀으로 구성되며 CD, RxD, TxD, DTR, GND, DSR, RTS, CTS, RI가 존재함.
EIA에 의해 규정되었으며 데이터단말기와 데이터 통신기 사이의 인터페이스에
대한 전기적인 인수, 컨트롤 핸드쉐이킹, 전송 속도, 신호 대기시간 등이 정의됨.

## 485 통신

노이즈에 강하 장거리 전송이 가능한 대표적인 동기식 직렬 통신 표준임.
장거리 데이터 전송을 지원하도록 설계되었으며 균형 잡힌 차동 신호 방식을 사용하여 전기적 노이즈를 줄이고 여러 장치가 동일한 네트워크 회선을 공유할 수 있도록 합니다.

## 차이점

| 구분 | 232 | 485 |
|---|---|---|
| 전기적 특성 | - 단방향 통신이 default<br>- 전압 레벨이 높아야함(정확한 정보 전달)<br>- 노이즈에 취약<br>-15V ~ 15V | - 반이중 통신 ->양방향<br>양방향 통신이기에 전압을 낮춰야함<br>신호의 균등성 유지 중요<br>-7V ~ 12V |
| 통신 방식 | 비동기 전송: 개별적인 문자<br>저속 통신에 사용<br>하나의 문자만 전송 가능 | 동기 전송: 여러 문자 묶어서 전송<br>고속 통신 지원, 여러 디바이스 제어<br>여러 센서 데이터 수집 가능 |
| 케이블 구성 | 9핀 D-Sub 커넥터<br>전용 케이블 필요<br>(송수신기 전기적 특성때문) | 2개 전송선, 2개 수신선 사용 |
| 전송 거리 | 이론상 15m, 최대 30m | 이론상 1200m, 최대 2500m |
| 최대 전송 속도 | 19200bps | 10Mbps |

## 장단점

| 구분 | 232 | 485 |
|---|---|---|
| 장점 | 저비용 구현 가능<br>일반적 PC와 통신에 적합<br>단거리 통신에 적함 | 장거리 통신 가능<br>전송 속도 빠름<br>다중 장치 간 통신에 적합 |
| 단점 | 거리의 한계 존재<br>노이즈에 취약<br>전송 속도 느림 | 대용량 데이터 전송에 한계<br>232보다 구현하기 복잡함<br>초기 구현 비용 높을 수 있음<br>통신 구조 설계가 중요함 |
