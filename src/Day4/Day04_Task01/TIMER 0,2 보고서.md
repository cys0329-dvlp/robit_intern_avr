#TIMER와 COUNTER
* 타이머: 입력 클럭이 일정한 주파수 펄스 -> 내부 counter 입력으로 시간 측정 가능
* 입력 클럭 주파수가 일정하기 않음 -> 외부 입력 신호는 counter 입력으로 받음 -> 외부 발생 event 횟수 측정 가능
* overflow: Timer 혹은 Counter에서 overflow가 발생 -> 해당 비트가 Set -> timer overflow interrupt 사용 -> 일정 간격으로 interrupt 사용 가능
